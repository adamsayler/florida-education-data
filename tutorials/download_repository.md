# Download *Florida Education Data* repository

1. Navigate to the [Florida Education Data](https://github.com/adamsayler/florida-education-data) website.

   <img src="/tutorials/img/01_download_url.jpg"
        alt="Download URL"
        style="display: block; width: 65%; max-width: 400px; height: auto; margin-top: 0.5rem;">

2. Locate and click the blue **Code** button. Select **Local** and then click **Download ZIP**.

   <img src="/tutorials/img/02_download_zip.jpg"
        alt="Blue Button Zip"
        style="display: block; width: 65%; max-width: 400px; height: auto; margin-top: 0.5rem;">

3. Once downloaded, open the folder where the ZIP file was saved.

   <img src="/tutorials/img/03_download_open_downloads.jpg"
        alt="Go to ZIP"
        style="display: block; width: 65%; max-width: 400px; height: auto; margin-top: 0.5rem;">

4. Right-click on the file and select **Extract All...**

   <img src="/tutorials/img/04_download_extract_files.jpg"
        alt="Extract All"
        style="display: block; width: 65%; max-width: 400px; height: auto; margin-top: 0.5rem;">

5. Select a location to save the extracted files, such as the Documents folder.

   <img src="/tutorials/img/05_download_extract_files_location.jpg"
        alt="Extracted files location"
        style="display: block; width: 65%; max-width: 400px; height: auto; margin-top: 0.5rem;">

6. Open the saved-to folder and inspect the contents.

   <img src="/tutorials/img/06_download_inspect_contents.jpg"
        alt="Go to extracted files"
        style="display: block; width: 65%; max-width: 400px; height: auto; margin-top: 0.5rem;">
