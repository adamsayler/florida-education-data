# Download **Florida Education Data** repository

1. Navigate to the [Florida Education Data](https://github.com/adamsayler/florida-education-data) website.
   ![Download URL](/tutorials/img/01_download_url.jpg)

2. Locate and click the blue **Code** button. Select **Local** and then click **Download ZIP**.
   ![Blue Button Zip](/tutorials/img/02_download_zip.jpg)

3. Once downloaded, open the folder where zip file as saved.
   ![Go to zip](/tutorials/img/03_download_open_downloads.jpg)

4. Right-click on the file and select **Extract All..**.
   ![Extract All..](/tutorials/img/04_download_extract_files.jpg)

5. Select location to save the extracted files, such as Documents folder.
   ![Extracted files location](/tutorials/img/05_download_extract_files_location.jpg)
   
6. Open the saved-to folder and inspect contents.
   ![Go to extracted files](/tutorials/img/06_download_inspect_contents.jpg)
