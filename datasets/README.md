# Datasets directory

The datasets directory is broken down into subdirectories to contain the datafiles in different usable formats. The `csv`, `excel`, and `parquet` folders contain the same data, but in different formats depending upon your needs.

# Datasets list

Please check out the [sources.md document](/references/sources.md) for information from where the data were obtained.

- **UfteStudentEnrollmentHistory**: Contains information related to student FTE from each of the calculation periods.
- **CapitalOutlayFteByGradeLevel**: Contains grade level students counts.
