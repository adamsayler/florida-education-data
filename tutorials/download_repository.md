# Download *Florida Education Data* repository

1. Navigate to the [Florida Education Data](https://github.com/adamsayler/florida-education-data) website.

   <img src="./tutorials/img/01_download_url.jpg" alt="Florida Education Data repository URL" width="800">

2. Locate and click the blue **Code** button. Select **Local**, and then click **Download ZIP**.

   <img src="./tutorials/img/02_download_zip.jpg" alt="Download ZIP from the Code menu" width="800">

3. Once downloaded, open the folder where the ZIP file was saved.

   <img src="./tutorials/img/03_download_open_downloads.jpg" alt="Open the Downloads folder" width="800">

4. Right-click the ZIP file and select **Extract All...**

   <img src="./tutorials/img/04_download_extract_files.jpg" alt="Select Extract All" width="800">

5. Select a location to save the extracted files, such as your **Documents** folder.

   <img src="./tutorials/img/05_download_extract_files_location.jpg" alt="Choose a location for the extracted files" width="800">

6. Open the folder where the files were extracted and inspect the contents.

   <img src="./tutorials/img/06_download_inspect_contents.jpg" alt="Inspect the extracted repository files" width="800">
